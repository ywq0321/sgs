# 三国杀

本地网页联机游戏。使用经典标准包的 25 名武将、基本牌、锦囊、9 种武器、2 种防具和 6 匹坐骑。无第三方运行依赖，需 Node.js 24 以上。

## Netlify 部署

此仓库使用 **Netlify Server（Early Access）**，不是仅静态托管，也不是 Netlify Functions。已提供 `netlify/server/index.mjs` 和 `netlify.toml`，无需额外后端托管或数据库。

1. 将仓库推送到 GitHub，在 Netlify 导入该仓库。
2. 保留仓库根目录作为 Base directory。配置文件会设置构建命令 `npm run check`、发布目录 `public` 和 Node.js 24。
3. 在 Netlify 的项目环境变量中添加 **`ADMIN_PASSWORD`**，值为自行设置的 12～256 位管理密码；其作用域必须包含 **Functions**（Netlify Server 使用这一作用域），用于 Production；需要在预览部署中使用管理页面时也为相应上下文配置。
4. 部署或在修改变量后重新部署。构建应检测到 `netlify/server/index.mjs` 并生成 Server。若控制台只有静态页面或 Functions，请确认账户已支持 Netlify Server，且仓库目录没有选错。
5. 玩家访问网站根地址 `/`；管理员访问同一网站的 **`/admin`**，用 `ADMIN_PASSWORD` 登录。

服务使用 Frankfurt 区域，并明确限制 `scale.max = 1`。所有房间、在线连接、当前战局日志和管理员登录状态都保存在同一个进程内存中；重启、重新部署或空闲实例关闭后会清空，玩家需要重新建房，管理员需要重新登录。按要求不保存历史。

不要添加 `/* /index.html 200` 这样的全站重写规则，它会遮挡 `/api/*`、`/events` 和 `/admin`。静态资源由 Netlify CDN 提供，游戏接口和实时事件由 Server 接收。

管理页面可以查看房间和玩家、改体力、发指定牌、跳过回合、结束对局、重置房间、踢人和关闭房间。会影响大量状态的操作有确认步骤，操作会写入当前战局记录。密码只从环境变量读取，不会写进网页；没有配置有效密码时，管理登录默认禁用。登录 cookie 为 HttpOnly / SameSite=Strict，线上使用 Secure；管理操作另有同源和 CSRF 校验。

Netlify 没有本项目本地终端的交互输入。云端使用 `/admin`；停止或重新部署云端服务通过 Netlify 控制台操作，不提供网页 `quit` 命令。本地仍保留终端 TUI。

`.gitignore` 已排除 `.env`、`.node-runtime`、本地预览图及构建缓存。不要把真实管理密码写入 `netlify.toml`、前端文件或 GitHub。可以提交 `.env.example`。

官方文档：[入门与 Node.js HTTP Server 接口](https://docs.netlify.com/build/server/get-started/)、[环境变量、Node.js 版本和实例配置](https://docs.netlify.com/build/server/configuration/)、[实时连接](https://docs.netlify.com/build/server/real-time/)。

## 本地管理页面

可复制 `.env.example` 为 `.env`，填写自己的 `ADMIN_PASSWORD` 后使用 `start.cmd` 启动；也可以在 PowerShell 仅为当前终端设置：

```powershell
$env:ADMIN_PASSWORD = '替换为你自己的至少12位管理密码'
node server.mjs --tui
```

打开 http://localhost:3000/admin。`.env` 仅供本地读取，Netlify 上应使用环境变量。修改密码后重启本地服务。

## 自定义口令码

创建房间时可以设置 2～24 个汉字、字母、数字、下划线或短横线，例如 `三国夜战`、`friends-uk`。留空自动生成六位数字。英文大小写不敏感，全角字符会规范化，已占用的口令码会提示更换。朋友用同一个口令码加入。

口令码仅用于加入对应房间，与管理员密码独立。网址不再要求包含房间号，分享网站地址和口令码即可。

## 启动与退出

Windows 双击 `start.cmd`，打开 http://localhost:3000。启动器可寻找系统 Node.js 或此电脑记录的 Codex Node.js 路径。

服务器窗口现在是房主终端：输入 `quit` 或 `0` 正常关闭所有连接并退出，也支持 Ctrl+C。命令行启动：

```powershell
node server.mjs --tui
```

端口可通过 `$env:PORT=3001` 修改。关闭旧版本后重新启动，浏览器刷新即可加载更新。房间存放在内存，重启会清空。

## Radmin / ZeroTier

所有玩家加入相同虚拟网络。房主创建房间，其他人访问 `http://房主虚拟网络IP:3000`，点击「加入房间」，输入昵称和口令码。

终端会列出本机地址，可选择 Radmin / ZeroTier 对应地址。服务监听 `0.0.0.0`，Windows 防火墙需允许 Node.js 在对应网络通信。

## 房间和模式

房间人数不设上限。创建或加入房间前，先在武将卡片列表选将；每张卡片直接显示体力和技能。房主选择模式：

- 自由混战：至少两人，最后存活者获胜。
- 身份局：至少四人。第一座位为主公，其他身份随机分配；五人及以上主公体力上限加一。主公、忠臣消灭所有反贼和内奸获胜；反贼以主公阵亡获胜；内奸须独自存活。

游戏中暂停加入，结束后房主可以重新开桌。武将允许重复，以便支持任意人数。点击「退出房间」即可返回首页；对局中退出按阵亡处理，并终止当前结算后继续游戏。房主退出后自动交接管理权。独立标签页可模拟不同玩家；刷新同一标签页可恢复座位。

## 操作

- 点卡牌可多选，下方显示每张牌的具体效果。点玩家的「选择目标」按钮指定目标。
- 「使用」打出所选牌；武将转换技能在「作为」选择，例如武圣、龙胆、倾国、国色、奇袭、急救。丈八蛇矛需选择两张手牌。
- 主动武将技能在「技能」选择，然后按描述选牌和目标，点「发动技能」。青囊不选其他目标时默认治疗自己。
- 离间与借刀杀人的目标按点击次序结算；借刀第二目标可用「选择自己」指定自己。
- 装备分四个槽位：武器、防具、进攻坐骑、防御坐骑。同槽替换旧装备。装备区的牌可以通过允许的技能转换或消耗。
- 「结束回合」后若手牌超出体力值，需要选牌并「弃牌」；弃够后自动换人。
- 有响应时，面板显示所需牌、技能／装备选项和目标。按需选择后确认，也可以放弃。需要时页面会滚动到响应面板。
- 图鉴支持按卡牌、武将、技能名称搜索。描述由前后端共享的 `public/catalog.js` 提供。

## 机制

- 准备、判定、摸牌、出牌、弃牌与结束阶段；主动技能限次、锁定技能、转换技能、受伤与失牌触发。
- 存活座位环形距离、马术、攻防坐骑和武器攻击范围。
- 杀闪、无双双响应、决斗、青龙追杀、贯石斧强制命中、寒冰剑替代伤害、麒麟弓弃马、雌雄双股剑选择、青釭剑破甲、八卦阵和仁王盾。
- 拆桥、顺手、借刀、范围锦囊、五谷选牌、无懈及反无懈。
- 乐不思蜀、闪电判定和传递、鬼才改判、天妒、观星与洛神。
- 按座次求桃、急救、主公技、阵亡、身份公开与身份胜负、杀反贼奖励和主公杀忠臣惩罚。
- 基础牌堆 108 张（杀 30、闪 15、桃 8），按大房间人数扩充；花色和点数随机生成，并非逐张复刻实体牌的花色点数表。

当前图鉴是本版规则约定，未加入军争、神将、界限突破和其他扩展。没有 AI、超时托管或自动踢掉离线玩家；离线响应可由房主终端管理。不同发行版本的技能可能有差异。规则资料参照：[经典卡牌与武将规则索引](https://gltjk.com/sanguosha/rules/card/index.html)。

## 房主 TUI / sudo

`sudo` 是本游戏的作弊管理菜单，不是操作系统提权。不需要管理员权限；网页没有作弊接口。

```text
rooms                  列出房间
use 123456             选择要管理的房间
players                查看座位编号、武将、体力和手牌数
sudo                   进入作弊菜单
cards                  查看可发的卡牌编号
hp 2 3                 把 2 号位体力设为 3（1～体力上限）
give 2 赤兔 1          给 2 号位一张赤兔；也支持卡牌编号
skip                   清除当前结算，跳到下一位
finish                 强制结束当前对局
reset                  清空当前对局，回到等待状态
kick 2                 踢出 2 号位；游戏中会终止当前结算并换人
back                   返回普通菜单
quit                   关闭服务器
```

所有改变战局的管理操作都写入公开日志，并带 `[sudo]` 标记。可输入 `help` 随时查看菜单。一次最多发 50 张牌，限制仅用于防止误输入，不限制房间人数。

## 手机

推荐横屏使用。竖屏时默认显示横屏提示；点击顶部「全屏」或提示中的「横屏全屏」，会尝试进入浏览器全屏并锁定横屏。可用「退出全屏」或浏览器返回／Esc 退出，退出时解除方向锁定。

部分浏览器不提供网页全屏或方向锁定：全屏不可用时切换为沉浸布局，方向锁定不可用时提示手动旋转。浏览器要求用户主动点击，网页不会在加载时强制进入全屏。

横屏采用紧凑的牌桌／武将并排布局，底部固定操作，选牌说明浮在操作栏上方；支持 844×390、640×360 等常见横屏尺寸，异形屏边缘和底部保留安全区域。横屏「记录」按钮可查看战局日志。

适配 320 像素及以上的竖屏：底部固定操作栏，手牌和座位横向滚动，装备换行，图鉴与说明弹窗，日志默认折叠。模式、技能、响应和图鉴类别均为按钮选择，不使用下拉菜单。

卡牌图片是本地 SVG，不依赖外网，不使用官方卡图。没有外部字体依赖。
